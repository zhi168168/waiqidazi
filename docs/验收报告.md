## 阿里云真实 TTS 验证

用户配置北京地域业务空间后，qwen-audio-3.0-tts-flash 使用官方示例音色 longanhuan_v3.6 生成英文试音，WAV 已保存到 data/qa/aliyun-tts-check.wav。修复阿里云返回 HTTP OSS 链接时升级为 HTTPS 下载的兼容问题；真实返回 138284 字节音频。另修复官方 WAV 使用流式长度占位值的问题，规范化 RIFF/data 长度后正确时长为 2.88 秒（24kHz、单声道），避免播放器显示错误时长。使用这份真实 WAV 在隔离测试数据库验证保存、发布、三次读取以及相同语料复用，合成任务计数为一次；此业务链路检查复用了已生成文件，没有额外调用上游合成。14 个自动测试继续通过。
