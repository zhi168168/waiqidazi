## 账号与存储

认证采用 GitHub 项目 [Better Auth](https://github.com/better-auth/better-auth)，MIT 许可证，版本锁定 1.7.9，使用官方 PostgreSQL 适配器、密码哈希、HttpOnly Secure Cookie、数据库会话和请求限流。认证路径为 `/api/accounts/*`。数据库只监听本机，业务表在 `buddy` schema。

没有 SMTP 时，邮箱是未经验证的登录标识，注册可直接登录。注册完成或在「我的」里生成恢复码；原文只在生成时显示，数据库只存 SHA-256。忘记密码时使用邮箱、恢复码和新密码；恢复调用 Better Auth 自带的重置流程，旧会话作废，码用过即失效。恢复码遗失且忘记密码时不能自助找回。

配置 SMTP 后可开启真实邮箱验证和邮件重置；不要把未验证邮箱当作已验证联系方式。用户注销统一经过业务接口 `/api/me`，清理账号、聊天、记忆、收藏、反馈和恢复码。库的独立删除接口关闭，避免只删除身份而遗留业务数据。

音频在 `/srv/waiqi-data/audio`，经应用鉴权后提供。初始包含四条标记为「示例」的语料。AI 对话、英译与记忆使用原 DeepSeek 配置，语音使用原阿里 Qwen-Audio 配置。内容检查使用 `CONTENT_SAFETY_PROVIDER=llm` 的模型辅助分类，检查失败时拒绝处理；这不等同于独立商业内容审核服务，也不保证识别所有风险。

应用开机自启、异常重启。Certbot 自动续期证书。每天 UTC 19:17（北京时间次日 03:17）备份数据库到数据盘，保留约 14 天。这是同机数据库备份，不是异地容灾；音频原文件仍在数据盘，当前没有额外异地副本。

```bash
systemctl status waiqiEnglish --no-pager
journalctl -u waiqiEnglish -n 80 --no-pager
systemctl restart waiqiEnglish
nginx -t
certbot renew --dry-run
/usr/local/sbin/waiqi-backup
```

## 部署与检查

`scripts/deploy-selfhost.py` 需要 Python paramiko，用 `WAIQI_SSH_PASSWORD` 环境变量提供 SSH 密码，`WAIQI_SSH_HOST` 和 `WAIQI_DOMAIN` 可指定服务器与域名。脚本从本地 `.env` 仅提取模型/语音字段，服务器管理员密码与认证密钥随机生成，不使用 SSH 密码。首次 SSH 主机密钥必须已经在本机 known_hosts 中确认。

脚本打包源代码，创建新版本目录，安装依赖并构建，初始化业务及认证表，配置环境、Nginx 和服务，再建立每日备份。**GitHub 推送不会自动更新此自建服务器**；应用更新需要运行部署脚本。旧版本目录保留，可手动切回；数据库迁移前另做备份。

```powershell
python scripts/deploy-selfhost.py
pnpm test
pnpm build
```

认证的真实集成验证（创建并删除自己的临时账号）：

```bash
SELFHOST_BASE_URL=https://154-94-226-162.sslip.io node --test tests/selfhost.integration.mjs
# 另加 LIVE_MODEL_TEST=true 会真实调用模型，产生供应商费用。
```

初始语料脚本 `scripts/seed-selfhost.mjs` 使用管理员 API，生成真实语音并发布示例；按英文正文去重，不会在重跑时无限复制。语音失败时停止，不自动重试计费任务。

更换域名需要同时更新 Nginx、证书、`BETTER_AUTH_URL` 并重启服务。旧域名 Cookie 不会自动转移，新域名需要重新登录。
