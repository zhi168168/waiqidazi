业务开发与本地验证已完成。已选择 DeepSeek 官方 `deepseek-flash` 与阿里云官方 `qwen-audio-3.0-tts-flash`。

## 当前接入状态

- DeepSeek：`https://api.deepseek.com`，真实英语流式回复与 JSON 记忆提取已通过。此产品默认关闭思考模式，避免短回复 token 预算被模型默认推理耗尽；可通过 `LLM_THINKING` 更改。
- 阿里云：专用 `services/audio/tts/SpeechSynthesizer` 协议适配已完成；保存官方返回 URL 对应的 WAV 文件，供小程序和管理员重复播放。专用协议及音频路由的本地测试已通过，北京地域业务空间已配置；真实 TTS 合成、WAV 下载与本地保存已通过。
- 暂用官方示例音色 `longanhuan_v3.6`，合成语速为默认值；播放器可调整播放速度。后续可按需要更换音色。
- 密钥只存在本机 `.env`，本文与源码不记录密钥。

## 获取阿里云业务空间与地域

1. 登录阿里云百炼控制台，在地域选择器确认所用地域。根据当前国内官方文档，所选 Qwen-Audio-TTS 非实时模型仅在北京可用，对应 `cn-beijing`。
2. 进入 [业务空间管理](https://bailian.console.aliyun.com/settings/workspace)，查看并复制所用空间的 Workspace ID。也可在控制台右上角的当前业务空间信息入口查看 ID。
3. 核对 API Key 属于同一地域和同一业务空间。
4. 配置 `TTS_WORKSPACE_ID` 和 `TTS_REGION` 后，服务端会构造 `https://<WorkspaceId>.<region>.maas.aliyuncs.com/api/v1` 地址。

核对的官方文档：

- https://help.aliyun.com/zh/model-studio/obtain-the-app-id-and-workspace-id
- https://help.aliyun.com/zh/model-studio/qwen-tts
- https://api-docs.deepseek.com/guides/thinking_mode

## 请指定的信息

| 用途 | 需要的信息 |
|---|---|
| 对话 LLM | 供应商、模型名称/版本、API 基础地址、接口文档或协议、密钥 |
| 记忆提取 | 是否复用对话模型；若独立，提供对应模型、地址和密钥；需支持可靠的 JSON 输出 |
| 语料朗读 TTS | 供应商、模型名称/版本、接口协议、音色 ID、口音、语速、密钥 |
| 微信身份 | 小程序 AppID、服务端 AppSecret、已认证主体及可用类目 |
| 上线环境 | HTTPS 域名、服务器、内容安全服务、数据存储/备份与保留规则 |

密钥写入本机 `.env` 或生产密钥管理服务。不要写进小程序、网页源码、Git 或截图。聊天中可以先提供供应商与模型名称，密钥随后配置到本地即可。

## 当前可配置项

```dotenv
LLM_BASE_URL=https://your-provider.example/v1
LLM_MODEL=your-chat-model
LLM_API_KEY=

# 以下为空时复用 LLM；MEMORY_MODEL 非空时三项均需配置
MEMORY_BASE_URL=
MEMORY_MODEL=
MEMORY_API_KEY=

TTS_BASE_URL=https://your-provider.example/v1
TTS_MODEL=your-speech-model
TTS_API_KEY=
TTS_VOICE=your-voice-id
TTS_PROVIDER=your-provider
TTS_MODEL_VERSION=your-version
TTS_ACCENT=unspecified
TTS_SPEED=1
```

基础地址不含具体 endpoint；例如配置到 `/v1`，适配器再追加 `/chat/completions` 或 `/audio/speech`。密钥采用服务端 `Authorization: Bearer`。兼容接口不保证供应商都接受相同参数；正式接入时需根据供应商文档调整。

LLM 适配器支持 JSON 回复与 SSE 增量解析；记忆提取使用 JSON 格式。TTS 当前请求 MP3 二进制文件，配置与文本共同计算资源哈希；相同音频普通播放不调用模型。供应商异步任务、非 Bearer 鉴权、WebSocket 或其他音频格式需要专用适配器。

失败任务不自动无限重试。更换全局音色只影响新保存的版本；原有音频不会自动重新收费生成。超时可能已经计费，手动重试需先核对供应商记录。
