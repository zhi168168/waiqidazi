# 场景语料库

首页只展示四个一级场景：工作汇报、协调同事、客户沟通、面试。两列大按钮，每个入口含线性图标、场景名称、一句说明和查看表达指引。保持原有绿色主色，使用浅绿、浅蓝、浅砂和浅紫区分入口，不显示搜索框、筛选项或语料空状态。

点击按钮使用原生 navigateTo 进入 pages/scene/index。内页显示所选场景的搜索、细分类、沟通方式、语气和语料列表；每次请求都携带一级场景 ID。使用微信导航栏返回，首页保留原状态。语料点击进入原详情页。
