# 上班搭子 UI 改版
当前实现已更新为“职场英语搭子 · 温暖的专业感”，以 [ui-v3/设计规范.md](ui-v3/设计规范.md) 为准。以下为旧版本记录。
方向：成人职场场景的简洁聊天产品；浅灰白底、深青绿主色、白色助手消息和青绿色用户气泡。现有信息架构与业务不变。
参考：GitHub nextlevelbuilder/ui-ux-pro-max-skill 的原生移动端规则。搜索结果的营销页面模式与儿童字体不适合本产品，不采用；参考扁平布局、对比度和触控间距规则。
主色 #186B59，背景 #F5F7F8，正文 #202C32，次要文字 #65717B，边界 #E3E8EB。
系统字体 -apple-system / BlinkMacSystemFont / PingFang SC / Microsoft YaHei；正文 16px，标题 22px，辅助至少 12px（窄屏保持可读字号），间距使用 rpx；正文行高 1.65。
全屏聊天使用 height:100%（微信页面可用高度），消息区 height:0 + flex:1；输入栏不使用视口减安全区的重复计算。发送按钮固定 96rpx 触控尺寸、禁止换行；输入允许收缩。
消息中保留原文，使用原生 rich-text 的安全节点展示段落、强调与列表，不直接渲染模型 HTML。
语料库：搜索框、场景筛选、轻量列表；我的：记忆、历史、收藏和隐私入口优先，个人偏好按需展开。
底部导航使用统一线性图标，原生 tabBar 要求 PNG：以 SVG 母版导出 96px PNG，而非在 WXML 内画矢量。
首次隐私仍是弹窗；不恢复手动话题和记忆选择。
当前没有图片生成工具，也没有可操作的微信模拟器接口；通过实际 WXML/WXSS 编译器和隐藏的离线布局核对页验证，离线核对页不作为学习端交付。
