# UI 改版核对

参考技能：https://github.com/nextlevelbuilder/ui-ux-pro-max-skill 。已读取 SKILL.md 和原生端 pro-rules.md，并执行设计系统与触控查询。搜索返回的营销页面布局和儿童字体不适合本产品，未采用。

设计规范见“小程序UI设计规范.md”。当前环境没有图片生成工具，未生成或声称用户批准过图片概念。

验证方法：实际 WXML/WXSS 转换为隐藏的离线静态布局核对页，在 Codex IAB 检查 320×844、390×844；不是微信模拟器截图，不提供浏览器学习端。通过 view_image 对照用户原图与改版图。

检查点：

1. 发送按钮不换行；窄屏测得 48×48px，输入框 244.72px，页面宽 320px，没有横向溢出。
2. 用户气泡靠右，搭子回复使用白色消息块，区分两种内容。
3. 正文 16px、辅助字至少 12px，段落间距 12px；原生 rich-text 的安全节点保留原文数字与强调，模型 HTML 不执行。
4. 深青绿主色、浅灰白底、深色正文，统一边界、圆角和间距。
5. 图标采用同一线性风格；原生 tabBar 只接受 PNG，以 SVG 母版导出 96px 图标。安全区由微信原生导航托管。
6. “我的”优先显示记忆与历史，偏好表单按需展开。隐私弹窗和自动话题继续保留。

文案调整：空聊天标题改为“今天，想聊点什么？”，保留两条原建议；我的副标题为“聊天、记忆与收藏，都在这里。”；音频标签为“AI 语音”，移除实现细节。没有新增业务数据或承诺。

验证结果：22 个测试通过；6 页面、20 个 JS/JSON 静态检查通过；微信 wcc 和 wcsc 编译通过。静态检查增加底部图标文件存在校验。

限制：未操作微信模拟器，实际字体、键盘避让、textarea 自动高度和原生滚动尚未实测。离线截图的系统导航为核对支架，微信使用其原生导航。未声称完成图片概念的 10/10 忠实度验证。
