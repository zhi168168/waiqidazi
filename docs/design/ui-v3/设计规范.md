## 固定文案

产品名称：职场英语搭子。

首页标题：说说，今天又发生了什么？

说明：工作上的烦心事，或生活里的小开心，都可以聊。聊完，顺手带走一句英语。

引导入口与对应输入值：
1. 什么事情都交给我做，我好欺负吗？
2. 明天要汇报了，我不知道怎么讲怎么办？

底部导航：职场英语搭子 / 场景语料库 / 我的。

不添加进度、积分、天数、课程、语音输入等新功能或虚构业务数据。浏览器核对对话与语料使用明确的隔离样例，不写入业务数据库。

## 设计系统

- 白底 #FFFFFF；辅助底 #F7F9F8；正文 #1D302B；次要文字 #687A74；边界 #E9EFEC。
- 品牌色 #187C65；浅绿 #EAF5EF；用户气泡 #EAF5EF；英语便签 #F2F7F3。不使用大面积渐变、投影或装饰图形。
- 系统中文字体；欢迎标题 28px/1.3，页面标题 26px/1.3，正文 16px/1.75，操作 14px，说明 13px，底部标注 11px。
- 主要内容左右 24px；间距 4/8/12/16/24/32/40px；聊天正文与便签沿同一左边界。
- 圆角：输入框 24px，场景按钮 20px，便签 16px，用户气泡 20px；头像圆形；边框仅用于可交互输入和必要分隔。
- 保留已有 SVG 母版，统一线宽、颜色并导出 PNG；发送使用向上箭头，保留无障碍标签“发送”。
- 主要按钮至少 44px 可触控；窄屏字体不缩小；引导和场景文案自然换行。
- 微信原生导航负责系统安全区；聊天内部保持 flex + 原生 scroll-view；不重复扣减安全区。
