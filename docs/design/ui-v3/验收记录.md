# UI v3 验收记录

## 已实施

- 原生小程序 `app.wxss` 建立统一色彩、字号、按钮、边界和圆角。
- 聊天首次进入采用白底、单个元气头像、居中的欢迎语和原文引导；取消重复品牌头。没有重画或声称生成新的 AI 人像。
- 对话正文去掉描边容器；用户消息为浅绿气泡；英语便签突出英文、保留复制和展开；EN 继续按需展开原有英文版本。
- 输入框与发送按钮整合为轻量输入区；发送使用独立 PNG 箭头和无障碍名称，保留 busy/loading、禁用、输入、回车逻辑。
- 四场景首页统一白色大入口与图标底色；场景内页、详情和个人资料页统一排版。“我的”没有增加已删除的次级入口。
- 图标保持现有 SVG 母版与 PNG 同步；产品名称与两条引导原文不变。
- 明示 AI生成；不增加新功能、假数据、业务配置或数据库改动。浏览器对话和语料为隔离的验收样例。

## 对照检查

| 检查点 | 源码预览与设计方向对照 | 处理 |
|---|---|---|
| 内容与名称 | 产品名、引导、四场景说明与顺序一致 | 原文保留；新增的 AI生成及提醒用于说明输出性质 |
| 首屏布局 | 白底、单个头像、清晰欢迎标题、两个引导入口 | 删除重复聊天品牌头，正文与输入区分开 |
| 字号层级 | 欢迎 28px、正文 16px、英文便签 18px、说明 12–13px | 辅助 AI 提示 11px；EN 为图标式控件 |
| 色彩 | 白色阅读区、浅绿用户气泡和低饱和便签 | 降低灰绿大面积使用，不添加渐变和重投影 |
| 容器与边界 | 回复为开放正文，只有便签和可操作入口保留容器 | 去除回复描边和各场景大面积四色背景 |
| 图标 | 已有线性 SVG 系统，新增发送箭头 | 修正浏览器转换器的嵌套 image 选择器，PNG 尺寸与原生源码一致 |
| 间距 | 以约 24px 的内容边距为主，便签与正文同轴 | 不通过缩小窄屏字体隐藏长文案问题 |
| 触控 | 320/375px 发送为 44×44px；390px 为 45.75×45.75px | 保留最小触控尺寸；链接增加最小宽度 |

没有可用 Image Gen，因此使用已确认的文字设计方向和完整页面规格进行实现。没有“用户批准的 AI 概念图”，不宣称 10/10 或逐像素匹配。通过 `view_image` 检查旧版截图与新版浏览器截图，确认层级、构图、配色、图标、留白及文案。

## 文件与使用

`chat-preview.png` 为首次进入/对话双屏核对图；`library-390.jpg` 与 `me-390.jpg` 为实际源码转换预览；`empty-320.jpg` 为窄屏图。

启动核对服务：在项目根目录运行 `node scripts/preview-miniprogram-ui.mjs`，访问 `http://127.0.0.1:8841/`。该服务只绑定回环地址，使用隔离样例，不连接实际业务 API。它用于设计核对，不是提供给用户的浏览器学习端。

修改前的完整小程序备份为 `miniprogram-before.zip`。正式运行仍使用微信开发者工具导入 `miniprogram` 并重新编译。
