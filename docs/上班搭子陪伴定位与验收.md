# 上班搭子：懂你、站在你这边

聊天主体服务于陪伴；英文学习通过独立便签发生。主体跟随用户语言与需求，中文倾诉用中文接话。安慰、吐槽、追问与解决方案按需出现，不按固定四步排列。先考虑用户处境，允许自然吐槽，不强行替领导辩护；不凭空编造背景、升级辱骂或把推测当事实。

## 回复与展示

模型返回 `reply` 与 `englishTip.expression / explanation`。服务端校验并分别保存，流式过程中只显示主体文字。小程序显示独立浅绿色“英语顺手学”卡片：英文直接可见，解释默认收起，支持展开、收起和复制。便签表达用户刚刚说出的意思，保留事实、情绪、数字与承诺，不把建议或推测的后果当成用户原话。

旧回复无需改写；已有会话可继续。默认人设自动迁移，管理员自定义人设保留，产品回复协议由服务端统一约束。

## 长期记忆

类别包括基本信息、职业、工作环境、自述性格、爱好、目标和偏好。只提取用户明确说出的事实，保存原话证据。情绪不转成人格标签，单个项目临时分工不固化成长期身份，模拟/翻译/隐私内容沿用排除策略。

记忆通过语义槽位并存。例如岗位、测试团队、跑步、读书是四条独立事实。新事实不能清空整个类别；同一槽位的更正替换旧事实，也可以显式引用被更正的旧记忆 ID。手动更正锁定对应事实，不阻止其他槽位增长。删除与停用沿用用户隔离、版本检查与删除标记。

跨会话上下文保留各类基础背景，再补充与当前消息相关的记忆，最多 40 条；不依赖“我好烦”必须包含岗位关键词。提取仍是异步任务：当前会话通过历史立即理解新信息，跨会话长期记忆在提取成功后可用。模型无法提取、超时或证据不合法时不写入。
