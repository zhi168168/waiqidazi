# 外企上班搭子

根据 `外企上班搭子微信小程序_需求文档_v0.1.md` 实现的首版本地内测项目。包含原生微信小程序、Node.js 业务服务、React 管理后台。DeepSeek 官方 LLM 和记忆提取已接通；阿里云 TTS 专用适配和真实合成已验证；没有在正常产品流程中使用模拟回复或假音频。

## 本地使用

需要 Node.js **24 或更高版本**（使用内置 SQLite）和 pnpm。

```powershell
cd D:\tools\waiqiEnglish
pnpm install
pnpm build
Copy-Item .env.example .env # 仅首次创建，已有配置不要覆盖
pnpm start
```

也可运行 `powershell -ExecutionPolicy Bypass -File scripts/start.ps1`；此脚本在 PATH 没有 Node 时尝试使用 Codex 的已有运行时。

- 管理后台：http://127.0.0.1:8838/
- 初始管理员用户名和随机密码：本机 `data/admin-bootstrap.txt`。如果首次启动前设置 `ADMIN_USERNAME` / `ADMIN_PASSWORD`，使用指定凭证。
- 本地配置：`.env`。模型密钥只在服务端读取，接口、网页和小程序不会接收完整密钥。
- 数据：`data/app.sqlite`；音频：`data/audio/`。关闭服务后备份整个 `data` 目录，包括 SQLite WAL 文件（如存在）。

源码改动后，网页运行 `pnpm build`；后端改动需要重启服务。开发网页可另开终端运行 `pnpm dev`（端口 8839）。

## 微信小程序

1. 用微信开发者工具导入 `miniprogram` 目录。
2. 将 `project.config.json` 的 `appid` 改为自己的小程序 AppID。游客 AppID 只能检查页面，不支持正式身份登录。
3. 修改 `miniprogram/config.js` 的 `baseUrl`。正式环境必须为 HTTPS 服务域名，并在微信后台配置 request 和音频相关合法域名。
4. 正式微信登录需要服务端 `WECHAT_APP_ID` / `WECHAT_APP_SECRET`，以及已补全并确认的隐私说明（`PRIVACY_POLICY_CONFIRMED=true`）。
5. 本地配置 `devLogin: true`，代码同时校验微信运行平台为 `devtools` 且地址为本地回环地址，才允许模拟器调试登录。本机 `project.private.config.json` 关闭域名检查，正式共享 `project.config.json` 保持检查开启。正式发布必须 `devLogin: false`，服务端 `ALLOW_DEV_LOGIN=false`，并配置真实 HTTPS 地址。

开发者工具若报合法域名校验错误，打开“详情 → 本地设置”，确认勾选“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”。修改编译兼容代码后，可通过“清缓存 → 清除编译缓存”再点击“编译”更新旧产物。

页面：聊天、语料库场景入口、场景语料、我的、语料详情、会话历史、我的记忆。语料库首页以两列大按钮展示工作汇报、协调同事、客户沟通、面试；点击后在对应场景内搜索、选择细分类和筛选语料。聊天主体优先陪伴：跟随用户语言和情绪，不机械要求安慰、吐槽、建议全部出现。每条新回复附独立的“英语顺手学”便签，英文表达直接可见，解释可展开/收起，支持复制；每条已完成的搭子回复右下角有 EN 小图标，点击展开完整英文版本，再次点击收起。首次按需翻译并持久缓存，历史纯文本回复同样支持。进入小程序时自动启动微信身份登录；首次以弹窗展示完整隐私与 AI 说明，同意后登录，不跳转页面。“我的”页未登录时提示微信登录，登录后显示头像和昵称；头像使用微信 chooseAvatar 能力，昵称使用 nickname 输入框，用户选择或填写后保存并在以后进入时恢复。微信身份登录不会自动获取真实头像和昵称。文字聊天通过定时读取后台状态展示主体增量内容，不展示 JSON 或混入英文便签；断线后仍可恢复结果，同时提供服务端 SSE 接口供支持 SSE 的客户端使用。正式模式先校验完整输出再交付，防止未审核的增量内容提前暴露。

## 已实现

- 微信 code 换取身份、服务端令牌、跨接口用户隔离；开发者工具本地联调身份仅允许回环连接。
- 同会话串行聊天、请求幂等、持久化状态、取消、重试、历史继续和删除。
- 熟悉朋友式聊天、站在用户角度的情绪回应与按需建议；独立英文表达便签、显式模拟会话与语料练习会话。
- 会话独立短期文档与近期消息、滚动摘要；长期事实来源校验、去重和历史状态；用户更正、删除、清空和停用。
- 记忆版本检查与删除标记，删除会话/账号后异步任务不恢复被删除内容；服务端自动筛选长期记忆，排除模拟练习、敏感信息、临时事项和文案；聊天中也可直接说“不要记住”。排除长期记忆不会删除原始聊天。聊天无需手动新建话题：服务端结合近期消息和摘要判断，仅高置信度独立任务自动新建会话；判断失败继续原话题。旧聊天与短期记忆保留，长期记忆按相关性调用，新话题只携带选中的真实背景，模拟与敏感内容不跨话题携带。练习情境由对话意图自动识别。
- 固定四大一级场景；细分类新增、修改、排序、停用和受关联约束的删除。
- 中文/英文/标签关键词搜索、场景/细分类/沟通方式/正式程度筛选，复制、收藏和语料练习。
- 内容版本、保存触发异步朗读、按朗读文本/供应商/模型版本/音色/口音/语速去重；多资料共享音频。
- 音频成功并人工试听确认后发布；英文更新等待新音频，旧已发布版本继续服务；失败可见并人工重试。
- 管理员内容/系统角色、人设与策略版本回退、审计、运行统计和反馈。

## 边界与待联调

- DeepSeek 真实调用已验证；阿里云真实语音已验证，微信主体仍待联调，未完成微信真机运行、提审或公网部署。英语自然度、记忆提取准确率、语音质量和 p95 目标必须实测。
- 首批学习资料未提供，正式语料库为空；不把测试内容当作已审核教学资料。
- 当前单条英文/朗读正文最多 4000 字符，超长内容明确拒绝，不截断；建议拆为多条语料。自动长文分段与拼接尚未实现。
- SQLite 与本地音频适用于单服务实例内测；不要启动多个业务实例共享数据库。对象存储/CDN、分布式队列、向量语义检索尚未接入。
- 长期记忆提取明确的基本信息、职业背景、工作环境、自述性格、爱好、练习目标与偏好；通过语义槽位保留多条独立事实，自然更正仅替换对应旧事实。不从情绪推断性格，不保存单个项目的临时分工。跨话题保留基础背景并选择相关记忆，不要求当前消息重复岗位关键词。尚未启用系统能力评级/重复学习观察。短期摘要按可配置近期轮次触发，模型指定后应按上下文容量调参。
- 内容安全是可配置服务接口（输入 `{text}`，输出 `{allowed: boolean}`），生产模式未配置时拒绝生成。模型、服务商训练政策、数据/备份保留与删除期限、微信备案和审核材料未确认，不宣称已满足上线条件。
- 付费、实时语音、语音输入、聊天回复音频不在本次首版范围内。
- 原文中的建议功能按上述首版实现；未知项未擅自设价格、正式英语变体或音色。
